# 11.6.9 IoTクラウドサービス

Webhook のような中継サービスを介さずに、直接 IoT デバイスを接続できるように設計されたサービスも、多くの事業者から提供されています。
これらのサービスを使うには、各サービス事業者が提供する API やプロトコルなどの仕様に基づいた開発が必要になります。

## IoT の国際標準化（W3C WoT、FIWARE）

こうした IoT 事業者間の非互換を解消し、多様なユースケースにも対応するための国際標準化が進められています。
* [WoT](https://www.w3.org/WoT/)
* [FIWARE](https://www.fiware.org/)
